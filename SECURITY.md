# Security policy

## Project status

BrandBench is a documentation foundation. No benchmark runner, hosted service, dataset, or released package is included. There are no supported runtime versions yet.

## Report a sensitive issue

Email [hello@getperceptcore.com](mailto:hello@getperceptcore.com) with the subject `BrandBench security report`.

Describe the affected file or commit, potential impact, and minimal reproduction steps. Redact credentials and private data. Do not open a public issue containing sensitive details.

If you discover an exposed credential, its owner should revoke it through the issuing service. Do not test the credential or send it in the report.

This project does not currently offer a bug bounty or a guaranteed response timeline. Methodology disagreements and ordinary documentation errors belong in public issues when they contain no sensitive information.
